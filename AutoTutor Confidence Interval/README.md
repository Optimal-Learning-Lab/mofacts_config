# AutoTutor Confidence Interval

Sample AutoTutor content package for the MoFaCTS AutoTutor unit type.

Files:

- `AutoTutor_Confidence_Interval_TDF.json`
- `AutoTutor_Confidence_Interval_stims.json`

The TDF wires the AutoTutor unit to cluster `0`. The structured AutoTutor curriculum script lives in the stimulus file under the first stim's `autoTutor` field.

Replace `YOUR_OPENROUTER_API_KEY` with a real local key before testing. The config sync script strips `openRouterApiKey` before commit/push and restores the local file from backup afterward.
