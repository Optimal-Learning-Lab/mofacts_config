# AutoTutor Correlation Causation

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Correlation_Causation_TDF.json`
- `AutoTutor_Correlation_Causation_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Distinguish association from causal inference, including direction, confounding, and the role of research design without dismissing correlation as useless.
