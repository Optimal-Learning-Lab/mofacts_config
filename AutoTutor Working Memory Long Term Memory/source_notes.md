# Source Notes: Working memory vs. long-term memory

Source roles satisfy the module requirement for at least one authoritative source, one misconception or learning-difficulty source, and one examples/problems source.

## MEM_OPENSTAX_NEURO
- Role: authoritative/examples
- Title: OpenStax Introduction to Behavioral Neuroscience 18.1
- URL: https://openstax.org/books/introduction-behavioral-neuroscience/pages/18-1-memory-is-classified-based-on-time-course-and-type-of-information-stored
- Notes used: Distinguishes working memory from long-term memory and gives examples such as holding a multi-digit code while using it.

## MEM_COWAN
- Role: authoritative
- Title: Cowan: What are the differences between long-term, short-term, and working memory?
- URL: https://pubmed.ncbi.nlm.nih.gov/18394484/
- Notes used: Reviews several definitions of working memory: short-term memory used for cognitive tasks, a multicomponent system, or attention managing short-term storage.

## MEM_GATHERCOLE_ALLOWAY
- Role: misconception/learning difficulty
- Title: Working Memory Underpins Cognitive Development, Learning, and Education
- URL: https://pmc.ncbi.nlm.nih.gov/articles/PMC4207727/
- Notes used: Defines working memory as a small amount of information held and used during cognitive tasks, contrasting it with vast long-term memory; supports overload misconceptions.

## MEM_UMN
- Role: examples/problems
- Title: University of Minnesota CEI: Working memory is limited
- URL: https://cei.umn.edu/teaching-resources/leveraging-learning-sciences/working-memory-limited
- Notes used: Explains retrieval from long-term memory back into working memory for active use and instructional implications of working-memory limits.
