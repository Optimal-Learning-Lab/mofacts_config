# AutoTutor Working Memory Long Term Memory

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Working_Memory_Long_Term_Memory_TDF.json`
- `AutoTutor_Working_Memory_Long_Term_Memory_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Explain working memory as limited active use of information and long-term memory as durable stored knowledge that can be retrieved back into working memory.
