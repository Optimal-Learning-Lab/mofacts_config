# AutoTutor Compound Interest

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Compound_Interest_TDF.json`
- `AutoTutor_Compound_Interest_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Explain compound interest as growth where each period's interest is calculated on the previous balance, and distinguish it from simple linear interest.
