# AutoTutor Natural Selection

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Natural_Selection_TDF.json`
- `AutoTutor_Natural_Selection_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Explain natural selection as non-teleological change in heritable trait frequencies caused by differential reproductive success in an environment.
