# AutoTutor Statistical Power

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Statistical_Power_TDF.json`
- `AutoTutor_Statistical_Power_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Interpret statistical power as a pre-study probability of rejecting the null for a specified effect size and test, not as the probability a specific result is true.
