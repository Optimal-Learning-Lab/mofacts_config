# AutoTutor Special Relativity

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Special_Relativity_TDF.json`
- `AutoTutor_Special_Relativity_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Explain special relativity for inertial frames as invariant light speed plus frame-dependent measurements of time and simultaneity, without treating effects as mere illusion or one-sided slowness.
