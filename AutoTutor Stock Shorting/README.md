# AutoTutor Stock Shorting

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Stock_Shorting_TDF.json`
- `AutoTutor_Stock_Shorting_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Explain short selling as borrowing and selling shares, then later buying shares to return them, with profit from price declines and potentially large losses from price increases.
