# Skeleton Demo

Upload `../Skeleton_Demo.zip` through the normal MoFaCTS content upload workflow.
Requires the application version that supports `skeletondemosession`.

The lesson contains exactly one display-only unit. Choose **Start camera**, allow
camera access, and compare the mirrored skeleton with your head, shoulder and arm
movements. **Stop camera** stops the preview. **Continue** finishes the unit.
Camera access requires HTTPS or localhost. Switching to another tab stops the
camera; choose Start camera again when you return.

There are no questions, answers, scores, recordings, or saved body positions.
The normal lesson progression mechanism still saves completion when Continue is
pressed. The referenced stimulus file has an empty cluster array; it contains no
placeholder practice items. The ZIP contains only the TDF and stimulus JSON files.

This is a visual demonstration. Inferred joint positions and depth are not
calibrated measurements. Parts hidden from the camera may have no overlay.
