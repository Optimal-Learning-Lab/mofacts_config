# AutoTutor Reinforcement Punishment

Small AutoTutor module for MoFaCTS.

## Files

- `AutoTutor_Reinforcement_Punishment_TDF.json`
- `AutoTutor_Reinforcement_Punishment_stims.json`
- `README.md`
- `source_notes.md`
- `calibration_debug.json`

The TDF wires one AutoTutor unit to cluster `0`. The stimulus file contains one cluster with one stim; the first stim contains `display.text` and the structured `autoTutor` script.

## Scope

Classify operant consequences by behavioral effect and stimulus change, especially distinguishing negative reinforcement from punishment.
